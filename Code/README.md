# Gaussian Elimination · Recorded Narration

This HyperFrames edition uses Ankit's recorded narration. Six repeated takes were removed, the voice was leveled, and the scene and subtitle timings were rebuilt. mix.wav contains the edited audio from the supplied recording. The archive includes the edit decision list in original-recording seconds.

Install Node.js, FFmpeg and Google Chrome. Run `npm ci`, then `npm run dev` to preview or `node render.mjs Gaussian-Elimination-Recorded.mp4` to render. Set CHROME_PATH if Chrome is installed in a different location.
